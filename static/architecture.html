Toutes les briques

Chaque boîte est un fichier ou un petit ensemble de fichiers. Les flèches suivent le sens des données ou des appels. Survolez une brique pour isoler ce qui lui est directement lié ; les parcours en haut rejouent un flux complet, étape par étape.

Une seule interface compte : CollectionAdapter. Tout ce qui est à droite ne connaît que ses quatre méthodes ; tout ce qui est à gauche peut être remplacé sans toucher à l’interface.
